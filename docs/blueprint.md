# **App Name**: The Final Prescription

## Core Features:

- Event Information Display: Showcases event title, a meaningful subtitle, and a real-time countdown to April 15, 2026, 11:59 PM IST.
- Interactive Agenda Timeline: Displays the day's events in a clear, sequential timeline format, detailing each segment from welcome to the DJ night.
- Conditional Food Menu Display: The detailed food menu will only be visible to attendees starting after April 13, 2026, ensuring anticipation.
- Dynamic Image Gallery: Leverages the Google Drive API to securely fetch and display images from specified Google Drive folders, automatically generating optimized preview images and offering a responsive lightbox viewing experience.
- Admin Dashboard for Gallery Management: A hidden panel, accessible by a specific keypress, provides an interface for administrators to manage the gallery. This includes dynamically adding, removing, and organizing images directly from Google Drive using the Drive API. It features an AI-powered tool that analyzes image content (via the Drive API) to suggest optimal preview crops and alt text.
- Secret Feature Reveal: An interactive button reveals a hidden message ('3rd B.Pharm') after being clicked three times, adding a playful, insider element to the website.

## Style Guidelines:

- Primary color: A sophisticated, deep blue (#136FF7) to convey depth, professionalism, and a 'cinematic' feel, reminiscent of medical aesthetics, yet vibrant enough to highlight key information.
- Background color: A nearly-black charcoal blue (#16181B) derived from the primary hue, providing a dramatic 'dark cinematic' backdrop for content to pop.
- Accent color: A brilliant gold (#F2CA3D) used for highlights, calls-to-action, and interactive elements, adding a touch of premium elegance and warmth to contrast the cool blue.
- Headline font: 'Alegreya' (serif), chosen for its elegant and intellectual character, fitting the 'premium' and reflective tone of a farewell event.
- Body font: 'Inter' (sans-serif), providing a clean, modern, and highly legible experience for all general text and longer content sections.
- Utilize modern, clean, and subtly outlined icons throughout the navigation and content sections. Icons for event categories, menu items, and media actions should maintain a cohesive style that complements the overall premium aesthetic.
- Employs a fully responsive grid-based layout for seamless viewing across all devices. The design prioritizes a 'glassmorphism' effect for the sticky navigation bar, combining blur and transparency to hint at the underlying content while remaining sleek and accessible. Content sections will feature ample white space (or dark space in this theme) to enhance readability and visual appeal.
- Incorporates a 'cinematic' animated particles background in the hero section to add dynamic visual interest. Loader animations, confetti effects, and smooth transitions powered by GSAP or AOS will create a fluid and engaging user experience, highlighting key interactions and section changes without distracting from the content.
